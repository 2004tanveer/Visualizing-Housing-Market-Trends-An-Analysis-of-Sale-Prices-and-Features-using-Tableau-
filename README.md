# Visualizing Housing Market Trends  
### An Analysis of Sale Prices using Tableau

## Project Overview
This project focuses on analyzing and visualizing **housing market trends** with a primary emphasis on **sale prices**. Using **Tableau**, an interactive dashboard was developed to uncover insights related to pricing patterns, location-based trends, and key factors influencing house prices.

The goal of this project is to help users, analysts, and stakeholders understand how different variables impact housing prices and to support **data-driven decision-making**.

---

## Objectives
- Analyze historical housing sale price data  
- Identify trends and patterns in the housing market  
- Compare sale prices across different locations and property features  
- Build an interactive Tableau dashboard for easy exploration  

---

## Dashboard Features
- **Sale Price Trends** over time  
- **Location-based Price Analysis**  
- **Property Characteristics Impact** (e.g., size, bedrooms, condition)  
- **Interactive Filters** for dynamic analysis  
- **KPIs** highlighting key metrics  

---

## Tools & Technologies
- **Tableau** – Data visualization & dashboard creation  
- **Microsoft Excel / CSV** – Data cleaning and preprocessing  
- **GitHub** – Version control and project sharing  

---

## Dataset
- The dataset contains housing market data including:
  - Sale prices  
  - Property location  
  - Property size and features  
  - Sale dates  

> *Note:* Dataset used is for educational and analytical purposes only.
